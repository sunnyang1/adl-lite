\begin{abstract}
This document provides supplementary material for the Applied Ontology submission of ``ADL Lite: An Event-First Capability-Lifecycle Registry for LLM Agent Ecosystems.'' It contains the complete OWL~2 DL axiomatization, the SHACL shape graph, the adversarial integrity test suite, the reproducibility protocol, complete proof sketches for all formal theorems, extended comparison tables, and implementation infrastructure details that were compressed from the main paper to meet the page limit.
\end{abstract}
